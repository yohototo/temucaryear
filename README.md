# TemuCaryear — AI Prompt Library for Vintage Year Metal Signs

**A curated prompt collection for AI-generated vintage decorative metal signs, year plaques, and e-commerce product design.**

**TemuCaryear** is an evolving AI image-generation prompt library focused on vintage year-themed decorative metal signs. It collects, organizes, analyzes, and expands reusable prompt structures to help creators generate diverse product designs for e-commerce applications.

TemuCaryear 是一个持续更新的 AI 图像生成提示词数据库，主要面向复古年份装饰金属牌、年份纪念牌及电商产品设计。项目通过收集、整理、分析和扩展现有提示词结构，帮助创作者快速生成更多具有差异化的产品设计。

## 📁 Repository Structure | 仓库文件结构

| File | Description |
|---|---|
| `yearprompt.md` | Main collection of year-themed AI prompts / 年份主题提示词数据库 |
| `black.md` | Reference blacklist for keyword screening / 禁用词参考数据库 |
| `README.md` | Project documentation / 项目说明文档 |

### Main Files | 核心文件

**1. yearprompt.md**

The primary prompt database. It contains different year-themed decorative metal sign concepts, including variations in typography, colors, materials, backgrounds, borders, textures, and composition.

主要提示词数据库，收录不同年份装饰牌的设计方案，包括字体、配色、材质、背景、边框、纹理和构图等多种变化。

**2. black.md**

A reference collection of potentially restricted terms, trademarks, brands, intellectual property names, team names, and other terms that should be screened before using newly generated prompts.

一个用于提示词筛查的参考词库，收录可能涉及平台管控、商标、品牌、知识产权、球队名称及其他需要审查的关键词。

**Important:** The blacklist is a screening reference, not a legal determination or a guarantee of marketplace approval.

**注意：** 禁用词库仅作为初步筛查参考，不代表法律审查结论，也不能保证商品通过平台审核。

## 🚀 How to Use | 如何使用

### Method 1: Browse Existing Prompts | 浏览已有提示词

**English**

1. Open `yearprompt.md`.
2. Browse existing year-themed prompts.
3. Select a design concept that matches your product direction.
4. Copy the complete prompt.
5. Adjust the year, typography, materials, colors, and decorative elements.
6. Submit the prompt to your preferred AI image-generation platform.

**中文**

1. 打开 `yearprompt.md`。
2. 浏览已有年份主题提示词。
3. 选择符合产品方向的设计方案。
4. 复制完整提示词。
5. 修改年份、字体、材质、配色和装饰元素。
6. 将提示词提交给自己使用的 AI 图像生成工具。

### Method 2: AI-Assisted Prompt Expansion | AI 辅助扩展

Use an existing prompt as a reference and ask an AI model to generate new variations.

将已有提示词作为参考，让 AI 根据原始设计结构和风格生成新的提示词。

**Example Instruction | 示例指令**

```text
Analyze the prompts in yearprompt.md.

Study their writing structure, design vocabulary,
composition, typography, materials, colors,
and vintage decorative styles.

Generate 50 completely new year-themed
decorative metal sign prompts.

Requirements:
- Direct front-facing view.
- Rectangular decorative metal sign.
- No mounting holes.
- Large central year numerals.
- Flat 2D printed artwork.
- No actual raised components.
- No embossing or shadows.
- Avoid trademarks, brands, and protected IP.
- Screen against every entry in black.md.
- Do not repeat existing prompt concepts.

Output English prompts only.
Each prompt must be independently usable.
```

### Method 3: Blacklist Screening | 禁用词筛查

Before using newly generated prompts, compare their text against the entries in `black.md`.

在使用新生成的提示词之前，应将提示词与 `black.md` 中的所有条目进行比对。

Recommended screening workflow:

1. Read the complete blacklist.
2. Normalize uppercase and lowercase characters.
3. Perform full-phrase matching against every blacklist entry.
4. Record all matched terms.
5. Review the context and possible trademark or IP risks.
6. Revise the prompt and run the screening again.

推荐筛查流程：

1. 读取完整禁用词库。
2. 统一英文大小写。
3. 对每条禁用词执行完整字符串匹配。
4. 记录所有命中内容。
5. 结合上下文检查商标和知识产权风险。
6. 修改提示词并重新执行筛查。

**Note:** A successful blacklist scan does not establish that a prompt is legally safe or compliant with any particular marketplace.

**注意：** 黑名单匹配通过不代表提示词不存在其他侵权风险，也不代表符合任何特定电商平台的全部审核规则。

## 🎨 Design Guidelines | 设计方向

The following visual characteristics represent important design directions in this collection.

以下视觉特征是本项目重点积累的设计方向。

| Category | Design Elements |
|---|---|
| Shape | Rectangular metal plaque |
| View | Straight-on frontal view |
| Typography | Oversized year numerals |
| Materials | Aged metal, oxidized copper, vintage enamel |
| Texture | Rust, scratches, chipped paint, faded printing |
| Colors | Antique gold, cream, burgundy, navy, teal, copper |
| Background | Geometric patterns, ornamental lines, industrial graphics |
| Composition | Centered, balanced, visually dominant year |
| Rendering | Flat 2D printed artwork |

设计重点：

- 年份数字必须具有足够的视觉占比。
- 采用不同的数字字体和数字表面纹理。
- 背景、边框和装饰元素应具有丰富变化。
- 保留复古金属装饰牌的整体视觉语言。
- 避免所有设计仅仅替换年份数字。
- 根据实际产品要求控制 2D 平面效果。
